# OonCore 0.3.51

A SS Eventos v2 utiliza o OonCore 0.3.51 a partir desta atualização.

Esta versão preserva as correções de formulários com múltiplas abas e corrige a validação declarativa `equalsField` quando referências MongoDB usam objetos `ObjectId` com `_id` autorreferente.

A atualização inclui os pacotes de frontend, backend e gerador, os respectivos lockfiles, a compatibilidade do manifesto e a documentação local do Core.
